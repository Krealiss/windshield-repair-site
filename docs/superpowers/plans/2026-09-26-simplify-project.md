# План спрощення проєкту

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Прибрати з проєкту Sveltia CMS і все, що існувало лише заради неї, та дати незнайомому розробнику готові рецепти типових правок.

**Architecture:** Astro лишається. Видаляються `public/admin/`, правила для `/admin/` у заголовках і `robots.txt`, а валідатор контенту скорочується до перевірок, яких не робить zod. Додається атрибут `data-phone` як задел під колтрекінг і розділ рецептів у README.

**Tech Stack:** Astro 7.3, Node 22, Cloudflare Pages, wrangler (локально), cloudflared (тунель), Lighthouse CI.

**Spec:** `docs/superpowers/specs/2026-09-26-simplify-project-design.md`

## Global Constraints

- **Тестового фреймворку в проєкті немає і він не додається.** Роль тестів виконують конкретні команди з очікуваним виводом: `npm run validate`, `npm run build`, `npm run build:preview`, `npx lhci autorun`, перевірки `grep` по зібраному `dist/`. Кожен крок «перевірити» нижче — реальна команда, а не опис наміру.
- **Показники не мають погіршитись:** Lighthouse performance, accessibility і SEO — 1.0 на обох сторінках; LCP не гірше 1363 мс; CLS дорівнює 0.
- **`npm run build` має падати на заглушках.** Це запобіжник, а не збій. `npm run build:preview` натомість проходить завжди.
- **Мова коментарів і документації — українська**, як у решті проєкту.
- **Кожна задача закінчується комітом.** Повідомлення українською, у стилі решти історії: що змінилось і чому, а не перелік файлів.
- Атрибут для колтрекінгу називається рівно `data-phone` — без значення, лише наявність.
- Файли, яких задачі не торкаються: `functions/`, `src/lib/`, `src/content/`, шрифт, іконки.

````markdown
## Типові правки

Шість речей, які доводиться робити найчастіше. Після будь-якої з них —

### Поміняти телефон

`src/content/contacts.yml`, поле `phone_main`. Формат строгий:
`+380XXXXXXXXX`, без пробілів і дужок.

Одне значення підставляється одразу в шапку, перший екран, липку панель
дзвінка, контакти, сторінку подяки й розмітку для пошуковиків. Більше
нічого шукати не треба.

Якщо підключений колтрекінг — заповніть `phone_tracking`. Він має
пріоритет при показі, але в розмітці schema.org лишається `phone_main`.

### Поміняти ціну

`src/content/services/*.yml`, поле `price_from`. Тільки число: `500`,
а не `від 500 грн`. Слова додаються самі.

Порядок у списку задає поле `order`.

### Додати пару фото в галерею

1. Покласти знімки в `src/assets/gallery/`
2. Створити файл у `src/content/gallery/`, наприклад `zirka-01.yml`:

```yaml
before: /src/assets/gallery/zirka-01-before.webp
after: /src/assets/gallery/zirka-01-after.webp
damage_type: star      # star | bullseye | combo | crack
size_mm: 12
duration_min: 40
published: true
```

Шлях мусить починатися з `/src/` — саме так, інакше збірка впаде.
Причина: поле описане через `image()`, і шлях на кшталт `/assets/…`
Astro шукає в теці `public/`, де його немає. Валідатор ловить цю
помилку до збірки і пояснює, що виправити.

Галерея зʼявляється на сайті **від чотирьох опублікованих пар**.
Менше — блок прихований.

### Додати відгук

`src/content/reviews/`, новий файл:

author: Андрій
text: Текст відгуку, до 400 символів.
rating: 5
date: 2026-09-20
source: Google        # Google | Viber | Особисто
```

Блок зʼявляється **від трьох відгуків**.
````
